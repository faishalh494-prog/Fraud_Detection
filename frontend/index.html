EXPLANATION INTEGRITY

TreeSHAP Log-Odds Contributions Caveat

All transaction explanations utilize tree-based Shapley values (TreeSHAP).

  • Model Space: SHAP contribution values are in log-odds model space, representing the shift in model margin from base value.
  • Not Probabilities: Contributions are not percentages or calibrated probabilities.
  • Evidence vs Proof: Model evidence identifies suspicious patterns requiring scrutiny; it does not prove fraudulent intent.
  • Calibrated Probability: Marked as Not available to prevent misleading false precision.
