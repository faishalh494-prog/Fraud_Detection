# Processed Dataset

The processed PaySim datasets are not stored in this repository because of their large file size.

Generated datasets include:

- syndicai_v1_processed.parquet
- syndicai_v1_train.parquet
- syndicai_v1_val.parquet
- syndicai_v1_test.parquet

These files are generated by the preprocessing pipeline in:

`src/features/syndicai_preprocessing.py`
